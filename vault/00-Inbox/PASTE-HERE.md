# 📥 Paste instructions here

This is the drop zone. Paste anything here — build instructions, ideas,
specs, messy notes, half-finished thoughts. Any order, any amount, any
number of times.

**Important — this file doesn't run itself.** Pasting something here saves
it, but nothing reads it automatically. After you paste, tell whichever
Claude session you're talking to (this one, or your local terminal):

> "Check `vault/00-Inbox/PASTE-HERE.md` and process it"

That session will then read what you pasted, figure out where it really
belongs (architecture doc, research note, operations playbook, etc.), move
it there, and clear this file back out for the next thing. Nothing gets
lost either way — once something's moved out of here, it has a permanent
home elsewhere in the vault.
